# AGENTS.md

This file provides guidance to Mistral Vibe when working with code in this repository.

## Shared Rules

The generic rules live in `rules/`. Both Claude and Vibe follow them. Edit the files in `rules/`, not here.

Read these two at the start of every session, and treat them as binding:

- `rules/project.md` — permissions, git policy, project overview, build commands, architecture
- `rules/code-style.md` — cross-cutting code style rules

## On-Demand Rules

Read these files in full before working on the relevant topic. They are not loaded automatically, to preserve context
when the topic is not in play.

- `rules/tdd.md` — before writing or changing any test (red-green-refactor cycle and its gates)
- `rules/testing.md` — alongside tdd.md (assertion shape, edge-case coverage, manual instructions)
- `rules/writing-style.md` — before writing or editing prose
- `rules/github-issues.md` — before editing a GitHub issue with `gh`
- `rules/backend.md` — before working on backend code (`src/`)
- `rules/frontend.md` — before working on frontend code (`frontend/`)

## Vibe-Specific Instructions

### Commit Messages

Follow the Git Policy in `rules/project.md` exactly. Vibe's built-in behavior appends a "Generated by Mistral Vibe"
line and a `Co-Authored-By` trailer to commit messages. Never add a co-author line, a "Generated by" line, or any other
mention of an AI assistant.
